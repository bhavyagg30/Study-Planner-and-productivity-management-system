Verdant

A web-based study management system that helps students plan, organise, and stay consistent with their study habits. Verdant combines practical productivity tools — task scheduling, a Pomodoro timer, goal tracking, streak tracking, and progress analytics — with a minimalist virtual garden that grows as a visual reflection of the user's consistency.

The interface is designed to be calm and distraction-free, using a warm cream and sage green colour palette, soft cards, and gentle animations, rather than competitive or game-like elements.

The Growth Concept

The virtual garden is not a game — it's a visual representation of consistency.

Symbol	Meaning
🌱	Completing one study session grows a small sprout
🌿	Maintaining a daily streak allows plants to flourish
🌸	Weekly goals unlock seasonal flowers
🌳	Long-term consistency adds elegant trees
🍃	Gentle animations and changing seasons reflect ongoing progress
Tech Stack
Frontend: React.js, React Router, Axios, Tailwind CSS
Backend: Node.js, Express.js, JWT, bcrypt
Database: MongoDB with Mongoose
Version Control: Git & GitHub
Testing: Postman, Jest
Deployment (suggested): Vercel/Netlify (frontend), Render/Railway (backend), MongoDB Atlas (database)
